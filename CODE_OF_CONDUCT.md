# Code of Conduct

Chrona expects technical discussion to remain respectful, specific, and constructive.

Harassment, discrimination, threats, deliberate credential exposure, and disruptive behavior are not acceptable.

Project maintainers may remove comments, close discussions, or restrict participation when conduct interferes with a safe and productive project environment.
