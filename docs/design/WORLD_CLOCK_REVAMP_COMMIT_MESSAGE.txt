feat(worldclock): revamp dashboard with native offline world map

Rebuild the World Clock destination around a local-time hero, responsive spotlight city cards, and a native Compose world map while preserving the existing persistent timezone model and navigation flows.

- Replaced the World Clock list-first layout with a clock-first dashboard hierarchy.
- Added a local device-time hero using the unified Chrona epoch ticker.
- Added responsive spotlight cards for London, Paris, New York, and Los Angeles when those saved zones exist.
- Added a wide-layout asymmetric composition with a larger lead card and a compact city grid.
- Added a compact two-column spotlight layout for narrower windows.
- Added a World Map card with a draggable UTC meridian, probe point, map-region highlight, and live UTC tag.

- Corrected the Android path rendering pipeline to scale the embedded 2000×788.8889 source geometry into the Compose canvas without distorting the source aspect ratio.
- Added English and Indonesian strings for the new World Clock sections and map guidance.
